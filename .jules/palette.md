
## 2024-05-23 - CLI Visual Hierarchy
**Learning:** Terminal output lacks visual scannability without structural markers, making errors and actionable next steps blend into standard output. The wiggumnator300 project specifically uses an emoji visual hierarchy ('❌', '⚠️', '💡', '✅') to structure CLI information.
**Action:** Apply the established emoji hierarchy to all CLI echo statements (errors, warnings, hints, success messages) to enhance scannability and accessibility for terminal users.
