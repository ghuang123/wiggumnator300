
## 2024-05-20 - Terminal Output Emoji Hierarchy
**Learning:** In CLI applications without traditional UI components, maintaining a consistent emoji visual hierarchy (e.g., '❌' for errors, '💡' for actionable steps) is a critical, codebase-specific UX pattern that drastically improves scanability and user guidance.
**Action:** Apply the project's specific emoji conventions to CLI echo statements to ensure error messages and solutions are immediately distinguishable.
