## 2024-10-12 - CLI Visual Hierarchy
**Learning:** The wiggumnator300 codebase uses a specific emoji visual hierarchy for terminal output (❌ for errors, ⚠️ for warnings, 💡 for actionable steps, ✅ for success messages) to improve CLI readability and scannability.
**Action:** Apply this emoji convention consistently whenever adding or modifying CLI echo statements to maintain the design system pattern.
