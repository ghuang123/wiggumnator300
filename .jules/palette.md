## 2024-10-18 - [CLI Emoji Visual Hierarchy]
**Learning:** The wiggumnator300 project uses a strict emoji-based visual hierarchy for terminal output: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages.
**Action:** When adding or modifying CLI feedback, always prepend the appropriate emoji to help users quickly scan and interpret the status and next steps.
