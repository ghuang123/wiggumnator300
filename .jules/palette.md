
## 2026-04-17 - Visual Hierarchy in CLI Errors
**Learning:** CLI applications lack native UI components, making terminal output the primary UX surface. Plain text errors often blend in, making them hard to scan.
**Action:** Always use visual hierarchy like emojis (❌ for errors, 💡 for actionable resolution steps) to structure CLI output, separating the failure from the solution for immediate scannability.
