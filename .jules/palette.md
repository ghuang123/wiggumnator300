## 2024-05-23 - Visual Hierarchy Pattern for CLI Output
**Learning:** The CLI design system relies on explicit, standardized emojis (❌, ⚠️, 💡, ✅) to create scannable visual hierarchy in terminal output, rather than relying on colored text or complex formatting.
**Action:** Always apply these semantic emojis to stdout/stderr messages in shell scripts to maintain the design system's consistent visual hierarchy.
