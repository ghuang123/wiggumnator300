## 2026-06-14 - [Visual Hierarchy in CLI Scannability]
**Learning:** In CLI-centric applications without standard web UI components, textual output serves as the primary user interface, and standard unstyled logs suffer from poor scannability.
**Action:** Establish a reusable UX pattern for CLI messages by prepending visual indicators ('❌ ' for errors, '⚠️ ' for warnings, and '💡 ' for actionable hints) to create a clear visual hierarchy and guide users to resolutions.
