## 2024-05-24 - CLI Visual Hierarchy
**Learning:** The wiggumnator300 CLI employs a specific emoji-based design system pattern for terminal output scannability: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages.
**Action:** Always maintain this emoji convention when adding or modifying echo statements in the project's bash scripts to ensure consistent CLI UX.
