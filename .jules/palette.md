
## 2024-10-30 - CLI Visual Hierarchy Pattern
**Learning:** Terminal output in this project relies on a strict semantic emoji system ('❌' for errors, '⚠️' for warnings, '💡' for actions, '✅' for success) to establish visual hierarchy without complex terminal color codes.
**Action:** Consistently apply the designated emoji prefix to CLI echo statements that convey warnings, success, or actionable steps to maintain intuitive user feedback.
