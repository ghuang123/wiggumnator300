
## 2024-05-24 - CLI Emoji Visual Hierarchy
**Learning:** The wiggumnator300 project utilizes a specific emoji visual hierarchy for its CLI outputs to improve scannability and user experience: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages.
**Action:** Apply this emoji visual hierarchy convention when adding or modifying terminal echo statements in bash scripts within this project to maintain consistent CLI UX.
