## 2026-06-22 - Improve CLI Output Scannability with Emojis
**Learning:** In CLI-based applications, plain text error messages and hints blend together, reducing scannability and making it harder for users to quickly identify actionable resolution steps.
**Action:** Use visual hierarchy by prepending '❌ ' to error statements, '⚠️ ' to warnings, '💡 ' to actionable hints, and '✅ ' to success messages to improve DX and accessibility.
