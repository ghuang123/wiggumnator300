## 2024-05-23 - CLI Terminal Output Hierarchy
**Learning:** The CLI tool uses a specific emoji-based design system for terminal output to improve scanability: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages.
**Action:** Consistently apply these emojis to echo statements in bash scripts to maintain the visual hierarchy and help users identify output types.
