## 2025-02-12 - Visual Hierarchy in CLI Output
**Learning:** Adding consistent visual hierarchy emojis (e.g., ❌ for errors, 💡 for actionable steps) in CLI scripts significantly improves readability and user experience by allowing users to quickly distinguish between failures and resolutions.
**Action:** Consistently apply visual hierarchy emojis to all error, warning, and actionable output in CLI scripts to enhance accessibility and scanability.
