
## 2024-11-08 - CLI Emoji Visual Hierarchy
**Learning:** The wiggumnator300 CLI tool uses a specific emoji convention ('❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages) to enhance CLI output readability and user guidance.
**Action:** Always apply this emoji visual hierarchy when adding or modifying `echo` statements in bash scripts within this repository.
