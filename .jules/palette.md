## 2024-05-24 - Terminal Emoji Hierarchy
**Learning:** The CLI tool uses a specific emoji visual hierarchy for terminal output: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages. This is a core part of the design system for CLI output.
**Action:** Apply this specific emoji hierarchy convention whenever adding or modifying CLI echo statements to maintain a consistent and intuitive user experience.
