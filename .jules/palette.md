## 2024-05-24 - CLI Output Hierarchy
**Learning:** The wiggumnator300 CLI uses specific emojis to create a visual hierarchy (❌ errors, ⚠️ warnings, 💡 action steps, ✅ success). Maintaining this is critical for the developer experience.
**Action:** When adding output to CLI scripts, ensure the exact emoji hierarchy is followed rather than standard text prefixes.
