## 2026-04-26 - Add visual hierarchy to CLI errors
**Learning:** CLI error messages are much easier to scan when prefixed with distinct visual cues like emojis (e.g., ❌ for errors, 💡 for actionable resolution steps) rather than plain text.
**Action:** Always prepend errors with '❌ ' and actionable steps with '💡 ' in CLI tool outputs to improve readability and developer experience.
