## 2024-05-24 - CLI Visual Hierarchy Pattern
**Learning:** The wiggumnator300 project uses a strict visual hierarchy for CLI outputs: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages.
**Action:** Ensure all script outputs, especially errors and user prompts, consistently apply these specific emojis to guide the user.
