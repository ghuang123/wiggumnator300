## 2024-05-24 - CLI Output Hierarchy
**Learning:** For a CLI app without graphical UI elements, visual hierarchy is driven strictly by specific unicode emojis (❌, ⚠️, 💡, ✅). Using inconsistent or missing emojis makes terminal output less scannable for users diagnosing issues.
**Action:** Always ensure CLI output aligns with the established visual hierarchy emoji system for rapid scannability and accessibility in text-only environments.
