
## 2024-05-20 - CLI Emoji Visual Hierarchy
**Learning:** The wiggumnator300 project enforces a specific emoji visual hierarchy ('❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for successes) for all terminal output to improve scannability and user experience.
**Action:** Always apply this emoji convention to new or modified echo statements in shell scripts to maintain a consistent CLI UX.
