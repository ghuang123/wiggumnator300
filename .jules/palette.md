## 2024-10-07 - CLI Visual Hierarchy
**Learning:** The wiggumnator300 CLI tool uses a specific emoji visual hierarchy for terminal output: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages. This is a reusable UX pattern for this design system.
**Action:** Always maintain this emoji convention when adding or modifying CLI echo statements to ensure a consistent and readable terminal experience.
