## 2026-04-27 - Enhance CLI scannability
**Learning:** Error messages in CLI applications become drastically more scannable and user-friendly when critical states are prepended with an emoji (e.g. ❌ for errors) and actionable steps are separated visually (e.g. 💡 for hints). It reduces cognitive load.
**Action:** Use this visual hierarchy pattern across all bash scripts and CLI output messages to guide the user naturally to the resolution.
