## 2024-10-24 - [Enhancing CLI scannability with visual emojis]
**Learning:** For shell scripts and CLIs, visual scannability is a key component of Developer Experience (DX). Users often skim terminal output, so using emojis like ❌ for errors, ⚠️ for warnings, and 💡 for actionable resolution steps makes logs much easier to parse and improves overall usability.
**Action:** Always prepend appropriate visual emojis to error, warning, and actionable hint messages in shell scripts to improve CLI output scannability.
