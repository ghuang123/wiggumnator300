## 2024-08-19 - Visual Hierarchy in CLI Output
**Learning:** CLI scripts lacking visual hierarchy can make errors, warnings, and next steps hard to read or notice, leading to poor developer experience.
**Action:** Consistently use emojis (❌ for errors, ⚠️ for warnings, 💡 for options/next steps, ✅ for success) to add visual weight and scanability to terminal output.
