## 2024-05-18 - Terminal Output Visual Hierarchy
**Learning:** The CLI tool uses a specific emoji visual hierarchy ('❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages) to improve scanability and user experience.
**Action:** When adding or modifying CLI echo statements, strictly maintain this emoji convention to ensure consistent visual feedback across all terminal interactions.
