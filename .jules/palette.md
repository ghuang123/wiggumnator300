## 2026-04-25 - Improve CLI Error Scannability
**Learning:** CLI error messages without visual hierarchy are hard to scan, especially in busy terminal output. Adding consistent visual cues (like '❌' for errors and '💡' for resolution steps) significantly improves the developer experience by separating the problem from the solution.
**Action:** When adding or modifying CLI error messages, consistently use emojis to establish visual hierarchy and separate the error description from the actionable resolution step.
