## 2026-06-10 - CLI Scannability with Emojis
**Learning:** For CLI tools and shell scripts, users often miss important errors or actionable next steps in walls of text. Emojis act as critical visual anchors to improve scannability.
**Action:** When writing CLI scripts, always prepend '❌ ' for errors, '⚠️ ' for warnings, and '💡 ' for actionable resolution steps to create a clear visual hierarchy.
