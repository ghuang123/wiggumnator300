## 2025-05-24 - CLI Visual Hierarchy
**Learning:** The wiggumnator300 CLI tool uses a specific emoji visual hierarchy for terminal output (❌ for errors, ⚠️ for warnings, 💡 for actionable steps, and ✅ for success messages) which improves readability and helps users quickly identify issues and resolutions.
**Action:** Always maintain this emoji convention when adding or modifying CLI echo statements across the project scripts.
