## 2024-10-02 - CLI Emoji Visual Hierarchy
**Learning:** The wiggumnator300 CLI tool uses a strict emoji visual hierarchy for its terminal output, replacing traditional text prefixes with standard emojis: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages.
**Action:** When adding or modifying CLI `echo` statements across any shell scripts in this repository, always prepend these specific emojis to maintain consistent visual communication.
