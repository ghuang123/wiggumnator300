
## 2024-10-28 - CLI Visual Hierarchy Pattern
**Learning:** The wiggumnator300 project utilizes a specific emoji-based visual hierarchy for terminal output UX: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages. This represents the core design system for CLI interaction in this codebase.
**Action:** Always maintain and apply this exact emoji visual hierarchy convention when adding or modifying CLI echo statements to ensure a consistent, accessible terminal UX.
