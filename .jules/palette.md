## 2024-06-02 - Improve CLI Scanability with Emojis
**Learning:** When users run CLI tools, plain text errors and hints often blend together. Adding visual emojis (e.g., ❌ for errors, ⚠️ for warnings, 💡 for actionable hints) significantly improves scannability and makes it easier for users to identify what went wrong and how to fix it.
**Action:** When creating or modifying CLI scripts, consistently prepend relevant emojis to error, warning, and informational/actionable messages.
