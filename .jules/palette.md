## 2024-05-09 - Adding visual feedback to error messages
**Learning:** CLI scripts error output can blend into standard console output, making errors harder to spot and resolve. Prepended visual cues ('❌ ' and '💡 ') significantly improve error message visibility.
**Action:** When writing or modifying CLI error messages, use visual hierarchy by prepending '❌ ' to error statements and '💡 ' to actionable resolution steps.
