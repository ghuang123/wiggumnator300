## 2024-10-24 - CLI Visual Hierarchy Pattern
**Learning:** Terminal CLI tools without visual distinction for different types of messages (errors, actions, warnings) cause higher cognitive load for users parsing the output. The wiggumnator300 project implements a specific emoji hierarchy (❌, ⚠️, 💡, ✅) to make CLI output scannable and accessible.
**Action:** Consistently apply established emoji hierarchy to all `echo` statements in bash scripts to ensure clear visual distinction between errors, actionable items, and informative text.
