## 2026-06-01 - Enhance CLI Scannability with Emojis
**Learning:** Using visual emojis (❌ for errors, 💡 for actionable hints, ⚠️ for warnings) dramatically improves the scannability of CLI outputs, helping users quickly distinguish between critical failures and next steps.
**Action:** Always prepend appropriate visual emojis to CLI feedback messages in shell scripts to establish a clear visual hierarchy.
