## 2026-06-04 - [Improve CLI Scannability with Visual Hierarchy]
**Learning:** For repositories focused on shell scripts or CLIs, improving CLI scannability by adding visual emojis to log outputs (like ❌ for errors, ⚠️ for warnings, and 💡 for hints) is a valid and expected UX/DX enhancement that significantly improves the developer experience.
**Action:** Always look for opportunities to add visual hierarchy and scannability to CLI scripts using consistent emojis for different log levels.
