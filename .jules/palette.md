## 2026-05-24 - CLI Visual Hierarchy
**Learning:** In text-only CLI tools without standard UI components, users rely heavily on rapid scanning. Lack of distinct visual markers for errors, warnings, and resolution steps causes cognitive friction.
**Action:** Always use a consistent set of emojis (❌ for errors, ⚠️ for warnings, 💡 for actionable resolution steps) to create visual hierarchy in terminal output.
