## 2024-09-24 - CLI Visual Hierarchy Convention
**Learning:** This project's CLI tool output uses a specific emoji visual hierarchy ('❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages) to improve cognitive accessibility and scannability.
**Action:** Always maintain and use this exact emoji hierarchy when adding or modifying CLI echo statements in shell scripts.
