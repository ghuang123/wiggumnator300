
## 2024-05-24 - CLI Visual Hierarchy using Emojis
**Learning:** Terminal-based UIs benefit significantly from visual anchors since they lack CSS styling. Using a consistent set of emojis for different message severities (e.g., '❌' for errors, '💡' for actionable steps) creates an immediate, scannable visual hierarchy.
**Action:** When working on CLI tools, always use the established emoji hierarchy to make console output more intuitive and readable, ensuring actionable steps are clearly distinguished from errors.
