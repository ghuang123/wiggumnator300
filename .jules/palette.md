## 2026-05-10 - [Visual Hierarchy in CLI Error Messages]
**Learning:** Plain text error messages in CLI tools often blend into terminal output, making it hard for users to distinguish between the core error and the actionable steps to fix it.
**Action:** When writing or modifying CLI error messages, use visual hierarchy by prepending '❌ ' to error statements and '💡 ' to actionable resolution steps to guide the user's attention.
