## 2026-06-05 - Improve CLI scannability with emojis
**Learning:** Adding visual hierarchy via emojis to CLI log outputs (e.g., ❌ for errors, 💡 for hints, ⚠️ for warnings) significantly improves scannability and UX/DX in shell scripts.
**Action:** When working on CLI tools or shell scripts, proactively use emojis like ❌, ⚠️, and 💡 to visually distinguish errors, warnings, and actionable steps in the console output.
