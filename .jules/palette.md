## 2024-10-24 - [CLI Visual Hierarchy Conventions]
**Learning:** The wiggumnator300 CLI tool relies on a specific emoji visual hierarchy for terminal output to guide users efficiently through scripts and loop logs.
**Action:** Always maintain the project's visual language by using '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages when adding or modifying CLI echo statements.
