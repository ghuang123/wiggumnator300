## 2024-09-13 - CLI Output Visual Hierarchy
**Learning:** The wiggumnator300 CLI uses a specific emoji visual hierarchy for terminal output: '❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages. This improves scannability and user comprehension of terminal output.
**Action:** Always maintain this emoji convention when adding or modifying echo statements in the CLI scripts to ensure consistent UX.
