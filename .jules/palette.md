## 2026-07-09 - CLI Output Scannability
**Learning:** Adding visual hierarchy (like emojis) to plain text CLI output significantly improves scannability for developers. It makes errors and actionable steps immediately apparent.
**Action:** When working on CLI tools or scripts, prepend error messages with ❌, warnings with ⚠️, and actionable resolution steps with 💡 to create a better Developer Experience (DX).
