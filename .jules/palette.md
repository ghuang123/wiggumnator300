## 2024-05-24 - CLI Visual Hierarchy
**Learning:** This project's CLI tools use a specific emoji hierarchy ('❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages) to improve scanability and user feedback.
**Action:** Always maintain this emoji convention when modifying or adding terminal output in bash scripts to ensure a consistent and delightful developer experience.
