## 2024-05-24 - CLI Error Scannability
**Learning:** In terminal-based workflows, plain text error messages often blend into regular log output, causing users to miss them. Using specific emojis (❌ for errors, 💡 for hints/actions) creates a visual hierarchy that significantly improves scannability and reduces cognitive load during debugging.
**Action:** Always prepend terminal error statements with '❌ ' and actionable resolution steps with '💡 ' to create clear visual boundaries.
