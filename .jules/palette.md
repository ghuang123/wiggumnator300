## 2024-12-04 - [Use Visual Hierarchy for CLI Scripts]
**Learning:** For a more engaging CLI user experience, rely on simple visual hierarchy elements like emoji prefixes. They make messages easier to scan at a glance and add personality without complex dependencies. For example, using '❌' for errors, '✅' for success, '⚠️' for warnings, and '💡' for tips or prompts.
**Action:** Enhance bash scripts by adding emoji markers to important log output and user-facing messages.
