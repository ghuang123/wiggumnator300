
## 2023-10-23 - CLI Visual Hierarchy
**Learning:** The wiggumnator300 CLI relies on a strict emoji visual hierarchy ('❌' for errors, '⚠️' for warnings, '💡' for actionable steps, '✅' for success) for all terminal output to guide users.
**Action:** When writing or modifying echo statements in bash scripts for this project, always apply the correct emoji prefix to match the message intent.
