## 2024-05-24 - CLI Emoji Hierarchy
**Learning:** The wiggumnator300 project uses a strict emoji visual hierarchy for terminal output ('❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages) to improve CLI readability and UX.
**Action:** Always maintain this convention when adding or modifying CLI echo statements to ensure a consistent developer experience.
