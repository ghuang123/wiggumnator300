## 2026-05-21 - Visual Hierarchy in CLI messages
**Learning:** Terminal output is hard to scan. Users often miss critical warnings or the actionable steps required to resolve an error because it blends into the rest of the text block.
**Action:** Prepend '❌ ' to error statements, '⚠️ ' to warnings, and '💡 ' to actionable resolution steps to create visual hierarchy and guide users' attention in the CLI.
