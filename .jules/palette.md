## 2026-04-18 - [Visual Hierarchy in CLI Errors]
**Learning:** In CLI environments, users often overlook actionable solutions hidden in plain text error messages. Using visual cues like '❌' for the error and '💡' for the resolution step significantly improves scannability and reduces cognitive load.
**Action:** Always prepend '❌' to error statements and '💡' to actionable resolution steps in CLI error outputs to improve readability and guide users to solutions.
