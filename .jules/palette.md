## 2024-10-24 - CLI Visual Hierarchy
**Learning:** The wiggumnator300 CLI tool relies on a specific emoji visual hierarchy ('❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages) to improve scanability of terminal output.
**Action:** Always maintain this emoji convention when adding or modifying CLI echo statements to ensure a consistent developer experience.
