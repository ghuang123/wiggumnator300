## 2024-05-24 - CLI Visual Hierarchy
**Learning:** The wiggumnator300 CLI tool implements a strict emoji visual hierarchy ('❌' for errors, '⚠️' for warnings, '💡' for actionable steps, and '✅' for success messages) to enhance terminal scannability and user experience.
**Action:** Always utilize this established emoji convention when adding or modifying echo statements in the project's bash scripts to maintain a consistent and delightful developer experience.
