## 2026-04-29 - Enhance CLI Error Message Scannability
**Learning:** Visual hierarchy using emojis significantly improves the scannability of CLI error messages, helping users distinguish between the error state and the required action faster than plain text blocks.
**Action:** Always prepend '❌' to error statements and '💡' to actionable resolution steps in CLI scripts to create a clear visual distinction between the problem and the solution.
