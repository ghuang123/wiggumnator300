
## 2024-10-27 - CLI Emoji Visual Hierarchy
**Learning:** Adding a consistent emoji visual hierarchy to CLI outputs (e.g., ❌ for errors, 💡 for actionable steps) significantly improves readability and user experience by allowing users to quickly scan for actionable information.
**Action:** Always apply the standard emoji hierarchy (❌, ⚠️, 💡, ✅) when writing or modifying CLI echo statements in terminal applications to ensure consistent and scannable visual feedback.
